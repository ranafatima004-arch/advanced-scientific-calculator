# 🧮 Modern Scientific Calculator

A sleek, responsive Scientific Calculator built with **React**, **Tailwind CSS**, and **JavaScript (ES6+)** with modern glassmorphism UI and dynamic trigonometric parsing. Created as part of my journey towards **MERN Stack** development.

---

## ✨ Key Features
- **Scientific Functions:** `sin`, `cos`, `tan`, `log`, `ln`, `√`, `x^y`, `x²`, $\pi$, $e$
- **DEG/RAD Switch:** Accurate degree and radian trigonometric calculations
- **Dual Display:** Live expression preview and high-precision result display
- **Clean Responsive UI:** Built with Tailwind CSS, dark mode layout, and keyboard support

---

## 🛠️ Tech Stack
- **Frontend:** React.js, Tailwind CSS, HTML5, JavaScript (ES6+)
- **Deployment:** Vercel
